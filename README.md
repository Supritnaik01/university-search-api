# University Search API

A simple frontend web application that allows users to search universities using a public API.  
Built using **HTML, CSS, JavaScript**, and **Axios**.

---

## 🚀 Features

- Search universities by **country** and **state**
- Fetches real-time data from a public Universities API
- Clean and responsive UI
- Smooth input focus animation
- Dynamic rendering of results

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Axios** (for API requests)

---

## 📡 API Used

- Universities API  
  Provides university data based on country and other filters.
